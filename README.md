# uniEventra

## Team
DevTrio

## Project Overview
UniEventra is a smart university event platform that helps students explore and join campus activities.
## Problem Statement
Students often miss campus events because announcements are shared on different platforms.

## Target Users
- Students
- Club Representatives

## Core Features
- Viewing upcoming campus events
- Searching and filtering events
- Viewing event details
- Joining events
- Creating and editing events
- Viewing participant counts

## Quality Attributes
- Simplicity
- Maintainability
- Medium scalability

## Architecture
UniEventra uses a layered architecture with Presentation, Application, and Data layers.

## UML Summary
The project design includes a use case diagram, class diagram, and sequence diagram.

## Conclusion
UniEventra aims to make campus event participation easier and more organized.
